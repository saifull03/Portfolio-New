Inventory Management System

Laravel 13 + Tailwind CSS + Vite

A modern, full-featured web application built on Laravel 13, Tailwind CSS, and Vite designed to streamline stock tracking, warehouse organization, employee management, and report export.

Laravel Version: 13.x
PHP Version: ≥ 8.3
Database: SQLite (MySQL/PostgreSQL ready)
License: MIT

🚀 Key Features

🌐 Public Landing Page

A responsive, dark-themed guest portal for user registration and demo account login. Logged-in users are automatically redirected straight to the main app dashboard.

📊 Premium Interactive Dashboard

Displays key inventory metrics (total products, warehouses, categories, and item types), a visual breakdown of products per item type, and a table of the latest products added.

📦 Advanced Stock Level Controls

Set Safety Stock limits and track Available Stock on a per-product basis. Shows warning badges when inventory levels drop. Enforces role-based permissions: Employees require Administrator approval to checkout below safety thresholds.

🏭 Warehouse/Location Management

Log and track multiple storage facilities with auto-generated unique warehouse codes (e.g., WH-001).

⚙️ Dynamic Product Code Generation

Automatically generates formatted product codes (e.g., ELEC0001, ACC0001) in real-time on the frontend based on the selected Item Type prefix, enforced securely on the backend model lifecycle.

👥 Employee Directory

CRUD interface for managing employee profiles, departments, designations, and contacts, complete with auto-generated employee IDs (e.g., EMP-001).

📈 Reporting & Data Export

Review stock distribution across warehouses and categories, and export the entire product inventory as a clean, downloadable CSV file.

🔒 Security & Authentication

Robust user registration, login, session management, and profile controls powered by Laravel Breeze.

🛠️ Technology Stack

Backend: PHP 8.3+, Laravel 13.x Frontend: Vite, Tailwind CSS, Alpine.js, Blade Templates, Vanilla JS Database: SQLite / MySQL / PostgreSQL Testing: PHPUnit

📦 Setup & Installation

1. Install dependencies and compile assets:

composer run setup

2. Seed the database with sample data:

php artisan db:seed

3. Run the local development server:

composer run dev

🧪 Testing

The codebase includes feature tests to verify CRUD functionality, product code generation, and access control. To run the test suite:

composer run test

📜 Commands Reference

Command Description
composer run setup Automatic installation of dependencies, environment setup, database migration, and asset compilation.
composer run dev Starts the concurrent development environment (server, vite, queue listener, logs).
composer run test Runs the test suite via PHPUnit.
php artisan db:seed Seeds the database with standard dummy data.
php artisan migrate:fresh --seed Resets the database and seeds it from scratch.

transiQo — Ride-Sharing Platform

MERN Stack + Socket.IO + Leaflet Maps

transiQo is a modern, full-stack ride-sharing application built with the MERN stack (MongoDB, Express, React, Node.js). It features real-time Socket.IO communication, Leaflet-powered map routing, dynamic fare calculation, a cash payment flow, and separate dashboards for passengers, drivers, and admins.

Frontend: React 18 (Vite, Tailwind CSS, Leaflet)
Backend: Node.js, Express, Socket.IO
Database: MongoDB (local or Atlas)
APIs: OpenStreetMap / Nominatim / OSRM

✨ Key Features

👤 Passenger Experience

  • • Interactive map pickup/dropoff selection.
  • • Live OSRM routing with distance/time estimates.
  • • Real-time driver matching via Socket.IO.
  • • Trip history with printable PDF receipts.

🚕 Driver Experience

  • • Online/offline availability toggle with persistence.
  • • Live ride request notifications delivered instantly.
  • • Full trip lifecycle control (accept, start, complete).
  • • Earnings dashboard with ride tracking.

🛡️ Admin Experience

  • • Admin dashboard with platform-wide stats.
  • • Comprehensive user & driver management.
  • • Active ride oversight and monitoring.
  • • Auto-seeded admin account on first boot.

⚡ Platform Highlights

Bi-directional Socket.IO JWT Authentication (Bcrypt) Responsive Dark UI PDF receipt exports Micro-animations

🚀 Getting Started

1. Clone the repository:

git clone https://github.com/saifull03/transiQo.git
cd transiQo

2. Backend Setup:

Create a `.env` in the backend folder with:

PORT=5003
MONGO_URI=mongodb://127.0.0.1:27017/transiqo
JWT_SECRET=your_strong_jwt_secret_here

Install dependencies and start the backend (available at http://localhost:5003):

cd backend
npm install
node server.js
🔑 Auto-seeded Admin Account: On first startup, an admin account is created with: admin@transiqo.com / admin123.

3. Frontend Setup:

Open a new terminal and run:

cd frontend
npm install
npm run dev

The frontend is served by Vite at http://localhost:5173.

📡 API Overview

Method Endpoint Description
POST /api/auth/register/user Register a new passenger
POST /api/auth/register/rider Register a new driver
POST /api/auth/login Login and receive a JWT token
GET /api/auth/profile Get authenticated user profile
PUT /api/auth/rider/status Toggle driver online/offline
POST /api/rides/request Request a new ride
GET /api/rides/history Get ride history for current user
PUT /api/rides/:id/status Update ride status
GET /api/admin/stats Platform-wide statistics (Admin only)

🔌 Socket.IO Events

Event Direction Purpose
join Client → Server Subscribe to user/rider room or shared riders room.
rideRequest Client → Server Send a new ride request to all online drivers.
newRideRequest Server → Client Broadcast a ride opportunity to available drivers.
rideAccepted Bidirectional Notify passenger that a driver has accepted.
updateLocation Client → Server Stream driver's live GPS location.
riderLocationUpdated Server → Client Push live driver location to passenger's map.

The system manages patient registrations, specialist consultations, hospital bookings, accommodation reservations, transport scheduling, and visa processing under a unified portal.

Frontend: HTML5, Modern Vanilla JS, CSS3, Tailwind CSS CDN
License: MIT

🚀 Installation & Setup Guide

Prerequisites

Ensure you have a local PHP web server environment installed (XAMPP for Windows, MAMP for macOS, LAMP stack for Linux).

Step 1: Place the Project

Clone or download the project and place it inside the document root of your local server:

/opt/lampp/htdocs/medtour  (or C:\xampp\htdocs\medtour)

Step 2: Set Up MySQL Database

  • Start Apache and MySQL from XAMPP Control Panel.
  • Navigate to phpMyAdmin (http://localhost/phpmyadmin).
  • Create a new database named mt_db.
  • Click on the Import tab, select mt_db.sql from the project root, and click Go.

Step 3: Run the Application

Navigate to the entrypoint URL on your browser:

http://localhost/medtour/index.php
